# 好记忆的标准（v4）

一条记忆值得留下，要**同时**满足四点：

1. **能迁移**：换个任务、换一天还用得上，不只是对这一件事成立。
2. **查不到**：下一个 agent 踩坑前实际找不到。字段名、接口签名、单处 SQL 一眼能看到的不算；跨模块隐含契约、两处实现不一致、要对照才发现的差异，仍算查不到。**本项目**的设计决定、模块职责、跨多处的代码地图、框架用法里的反直觉行为、用户环境的具体事实，就算"理论上翻代码能查到"，只要能省掉下一个 agent 重新探索的时间，也算查不到。
3. **改做法**：下一个 agent 知道它以后，会换一种做法（少问一次、少踩一次坑、换一种汇报方式）。
4. **有场景**：写清楚"当…时"用。说不出什么时候用的，等于没写。

## 三类值得记的东西

| 类别 | 是什么 | 例子 |
|---|---|---|
| A 干活偏好 | 用户希望 agent 怎么干活：汇报、语气、工作流、审查习惯 | 说人话；结论写在回复正文里；e2e 不能造假变绿 |
| B 项目知识 | 业务规则、设计决定和理由、模块职责/代码地图、用户机器和测试环境的具体事实 | 比率类指标只能建成衍生指标；为什么选了方案 X；某功能的权限逻辑分布在哪三段链路；本机连测试库要走哪个地址 |
| C 真会反复踩的坑 | 报错看不出原因、会反复浪费时间的坑 | 改了 UI 后要重启 dev server 再跑 e2e，不然测的是旧代码 |

A 类价值最高，而且确认后**每轮常驻注入**。

## 不记什么（用一句话判断）

- 只描述"这次发生了什么"的流水账、日记。
- 报错自己就说明了原因、改一次就好的问题：命令语法、参数写错、要切 JDK 版本。
- 代码里一眼能看到的事实：字段名、接口签名、单处 SQL 怎么写。跨文件才对得上的隐含契约不算「一眼能看到」。
- 阶段性、临时的用法（"先用 X 体验一下"）。探索中的经验可以留，但要标"探索："。
- 系统当前能力/缺口的**现状**描述（过几天就会变）；没有用户明确要求记成长期原则时，不要升格成偏好。
- 单次对话里的口径纠正，说不出常驻适用场景的；缺场景不要硬编"当…时"来救。
- 同类的事已经有原则了，就并进原则里，不再单记一条。
- **通用技术常识**：跟用户的项目、环境、干活方式无关的操作系统/shell/语言/工具行为（macOS 的 /tmp 是符号链接、bash 3.2 缺什么、JS 和 Java 的 trim 区别、pnpm 会注入哪些环境变量）。有经验的工程师本来就知道或一查文档就有；"换个项目也会撞上"不足以成为留下的理由。
- 保管凭据的套话（"不要打印密钥/连接串"）：用户不在意，不记。

## 对照例子（来自 sample30，附用户的点评）

**#17 e2e 造假**
- ✗ 原文："真实依赖（Trino 镜像、connector）上不来时，不要用 fake 执行器顶替……"。只对 Trino 这一个场景成立。
- ✓ 改成：**当**写或跑 e2e 测试时，不能为了变绿伪造环境或数据；优先用真实环境，真起不来就停下，原样汇报报错。（A 类）

**#4 Docker 监控（丢弃）**
- ✗ 原文："Docker 黑盒的 CPU 忙循环和业务错误日志当前不会被主动发现……"。这是系统**现状**，过几天就会变。
- ✓ 不记。现状描述会过期；用户没有把它说成长期架构原则时，不要自行升格成偏好再 rewrite。

**#8 指标口径**
- ✗ 原文："导出指标口径时，计算方式要拼成一段人类可读文本合并到单个字段……"。只讲这一张导出表。
- ✓ 改成：**当**给用户看的输出里涉及数据库原始字段时，要翻译成人能读懂的完整说法，不要把一堆内部字段原样摆出来。（A 类）

**#12 耗时口径（丢弃）**
- ✗ 原文："汇报耗时统一用端到端口径……"。单次对话里对某个数字口径的纠正，也没写适用场景。
- ✓ 不记。缺场景时不要自己编造"当…时"硬救；一次性口径纠正没有被用户说成常驻偏好就丢弃。

**#21 JDK 11、#5 curl 方括号**
- ✗ 报错本身就说明了原因，agent 重试一次就能修好，直接丢弃。
- ✓ 不记。

## 写法要求

- 正文：一句话，可以照着做，不写"本次 / 刚才 / 日期"。
- 场景：以"当…时"开头，不能只是把正文换个说法。
- 背景（why）：当时发生了什么、用户为什么这样要求。
- 证据：引用户原话或工具输出，必须逐字。父 agent 写给子代理的派活提示不算用户原话；但派活里提到的**通用干活方法**（怎么写测试、怎么验证、临时文件放哪）通常就是用户的习惯，按内容判断，只针对这一次任务的限制（"这个 worktree 别 commit""这个文件已定稿"）才丢。
