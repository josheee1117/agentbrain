# 2. 每轮召回准确率与资格策略（PR #49、#50，2026-10-14）

## 问题
1. 每轮召回（`ab recall` hook，最多 3 条）在真实库上准不准？漏召回和误注入的根因是什么？（#49）
2. 召回不全的另一半原因是资格策略：未确认的坑、未标 `for_workers` 的全局条目不允许进每轮召回。放开它们会不会带来误注入？（#50）

## 数据
- `eval/recall/queries.json`：95 条查询。
  - 46 条直接提问（`direct`，执行者按库里条目写的自然问题）。
  - 31 条真实提示词（`real`，从用户真实会话的提示词里挑出、库里有相关记忆的）。
  - 18 条负例（`negative`，库里没有相关记忆，不该注入任何东西）。
  - 每条带 `gold`：应召回的条目 id 前 8 位，由执行者对照库标注，用户没有逐条复核。
- 划分：`md5(id) % 10 < 3` 为 test（34 条：27 正 / 7 负），其余 61 条为 tune。调参只看 tune，没看过 test 的失败样例。
- 库：Mac 真实库的只读副本（10-14 上午，active 511 条）。条目元数据（不含正文）见 `eval/recall/active-meta.json`。

## 方法
- `eval/recall/eval.ts <repoDir> <homeDir> [--fill] [--split tune|test|all] [--out file]`：用指定代码版本的 `recall()` 对每条查询跑一次。`--fill` 在 Mac 上用真实 embedding 补算查询向量，存进 `emb-cache.json`（缓存未提交）。
- `sweep.ts`：在 tune 上扫 `RECALL_TUNING`（MIN_SIM、MIN_SIM_LEX、LEX_STRONG、LEX_WEIGHT、REL_MARGIN）。`diag.ts`：看 tune 上的漏召回。`dump.ts`：导出条目。
- 指标：
  - recall@3：正例中 gold 至少一条进了注入结果的比例。
  - eligible recall@3：只算策略允许召回的 gold。
  - MRR。
  - 注入精度：注入的条目里属于 gold 的比例。
  - 每条正例的注入数。
  - 负例误注入率：负例中有任何注入的比例。
  - 延迟 p50/p95。
- 复现（库副本需自备；原副本已删）：
  ```bash
  node eval/recall/eval.ts <repo@commit> <store副本目录> --fill --split all --out res.json
  ```
  对比的代码版本：base = #49 合并前的 `docs/agentbrain-v2-design`（cfb28e6 的父提交），agentbrain = cfb28e6（#49），polA / polB = 在 cfb28e6 上放宽资格的两个试验策略（polB 即 #50，4b5cd8e）。

## 根因（#49）
- FTS 按空格切词，中文整句 MATCH 永远不中；短词退回不排序的 LIKE，任意条目都能进来。改为 `lexical.ts`（中文二字 + 英文去虚词 + IDF 覆盖率）。
- 资格过滤在 top-20 之后做，还混进了归档条目。改为 `Store.similarities` 只对合格条目算余弦。
- 已确认条目过 0.55 就占满名额。改为"余弦 + 0.2 × 字面覆盖"，绝对门槛 0.62、相对门槛 0.1。
- 修完后全部 gold 的召回仍卡在 0.6 左右：36% 的真实需要指向未确认的坑，或未标 `for_workers` 的全局条目。

## 结论与决定
- 2026-10-14 12:26：合并 #49（cfb28e6），只修排序和过滤，不改策略。
- 2026-10-14 用户批准放宽（设计文档 §21 当日条目）。14:14 合并 #50（4b5cd8e）：未确认位每轮最多 1 条，可以放任何坑、规则、决定；全局条目不论 `for_workers` 都进主会话。
- polB 的 0.852 后来作为第 8、9、10 篇评测的基线。

## 保留意见
- gold 由执行者标注；31 条真实提示词来自用户会话。提示词原文文件当时含粘贴的密钥，已删除；本仓库里的 `queries.json` 是脱敏后的查询文本。
- test 只有 27 个正例，1 条约 3.7 个百分点。
- polB 的 eligible r@3 在 test 上从 0.842 降到 0.789，是因为放宽后"可召回"的 gold 变多、分母变大，不是变差。
