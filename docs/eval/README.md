# agentbrain 评测记录（索引）

本目录记录 agentbrain 做过的每一次评测：回答什么问题、数据怎么来的、怎么测、结果、据此做了什么决定、有哪些保留意见。
数据和脚本在仓库根目录的 [`eval/`](../../eval/README.md) 下，每个评测一个子目录。

时间一律为新加坡时间（SGT）。"执行者"指被派去做评测的 agent；"用户标注"指用户本人逐条打的标签。

## 隐私与可复现边界

- 仓库是私有的，但提交前仍逐文件跑了脱敏（`eval/lib/scrub.py`：密钥、Bearer、JWT、PEM、`key=value` 凭据、邮箱、手机号、身份证、家目录路径，另外把非 GitHub 的 URL、主机名、IP 换成占位符）。
- **没有提交**：store.db / index.db 快照、完整记忆导出（`active.jsonl`、`s60_props.json`）、embedding 缓存、会话转录原文。提交的是 id + 元数据版本（如 `eval/recall/active-meta.json`）和必要的标注样本（样本里的记忆正文已脱敏）。
- 完整原始数据只在本地：box 的 `/workspace/agentbrain-review/`，Mac 的 `~/.agentbrain/eval/`。快照多已删除，因此大部分评测**只能按方法重做**，不能逐字节复现同一数字；可以复现的是"给定结果文件 → 汇总表"这一步。
- 大部分脚本是一次性评测脚本，路径参数指向当时的工作目录（box `/workspace/...` 或 Mac `~/...`），复跑前需改成自己的快照路径。

## 通用口径

- **split**：召回类评测按 `md5(id) % 10 < 3` 划 test（留出），调参只看 tune。场景目录评测按题号 `k % 3 == 2` 划 test。
- **s30 / s60 / fresh30**：审稿评测的三批标注。s30 和 s60 是用户标注；fresh30 是执行者在跑模型之前自己标的，只作参考。**s60 已不是干净的留出集**（v4 标准和 2026-10-15 改标都是看过 s60 结果之后做的）。
- **"留"**：审稿结论为 keep / rewrite / merge 都算留；另有"merge 算没新增"的口径（merge 只归档候选、不改目标条目）。
